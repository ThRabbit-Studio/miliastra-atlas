# Miliastra Atlas v1.2.0 — 单表导出模式

在 v1.1.0 基础上新增**单表导出模式**：把所有指标按「日期」合并成一张大表，一行一天，便于直接筛选 / 透视 / 画图；同时保留原有的分表模式，面板上可自由切换。

---

## 一、本次新增

### 1. 导出模式可切换（面板顶部）

| 模式 | 产物 | 适合 |
| --- | --- | --- |
| **单表**（默认） | `数据概况` + **`<奇域名>_数据总表`** + `评论内容` + `数据说明` | 直接筛选、做透视表、插折线图、导入库 |
| **分表** | 约 18 张按主题拆分的工作表 | 逐项查看、只看某一类数据 |

> 注意：单表模式为了「一行一天」的整洁，**不含**接口原始明细类工作表（如各接口数据表）；需要那些就用分表模式。

### 2. 数据总表长什么样

一行 = 一天，列按需自动裁剪（某列全程无有效值就不出现）：

| 奇域名称 | 日期 | 奇域热度 | 平均游玩时长(秒) | 平均游玩时长(秒)(可读) | 评论数 | 封面点击率(%) | 平均推荐率(%) | 奇域总热度 | 创作者平均推荐率(%) | 游玩指数 | 奇域总数 | 订阅人数 | ≤1分钟 占比(%) | 1-3分钟 占比(%) | 3-5分钟 占比(%) | 5-7分钟 占比(%) | >7分钟 占比(%) |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 尘世执政录 | 2026-09-27 | 59 | 140 | 2分20秒 | 1 | | 0 | 156 | 58.33 | 100 | 7 | 533 | 12.5 | 62.5 | 12.5 | 6.25 | 6.25 |
| … | | | | | | | | | | | | | | | | | |
| 尘世执政录 | 2026-10-09 | 505 | 323 | 5分23秒 | 5 | 2.59 | 0 | 581 | 62.5 | 100 | 8 | 533 | 50 | 50 | 0 | 0 | 0 |

- **关键点**：主干来自接口返回的**每日序列**，不受页面上「近7日/近30日」图表显示范围限制，所以同一天的奇域热度、时长、评论数、点击率、时长分布占比会**落在同一行**
- 时长同时给「秒」和「可读」（`323` / `5分23秒`）
- 比率统一按 %（接口原始值为万分之一，已除以 100）
- 接口未返回有效值的单元格**留空**，不填 0

### 3. 自由选择分布区间

「单局游玩时长分布」在接口里有三套区间，单表模式下可用下拉自由选择：

| 选项 | 列 |
| --- | --- |
| 常规区间 | ≤1分钟 / 1-3分钟 / 3-5分钟 / 5-7分钟 / >7分钟 |
| 长区间 | ≤3分钟 / 3-6分钟 / 6-9分钟 / 9-12分钟 / >12分钟 |
| 超长区间 | ≤6分钟 / 6-13分钟 / 13-19分钟 / 19-26分钟 / >26分钟 |

### 4. 三项选择都会被记住

导出模式、导出区间、分布区间组都存在浏览器本地，下次打开面板保持上次选择。

## 二、安装

### A. 下载本页的 `miliastra-atlas-v1.2.0.zip`（推荐）

1. 解压到**固定目录**（例如 `D:\miliastra-atlas`，装了别删，Chrome 会一直引用它）
2. `chrome://extensions`（Edge：`edge://extensions`）→ 打开右上角**开发者模式**
3. 点**加载已解压的扩展程序**，选择解压出来的目录（含 `manifest.json` 的那一层）

### B. 从源码加载

```powershell
git clone https://github.com/ThRabbit-Studio/miliastra-atlas.git
cd miliastra-atlas
npm install     # 仅测试需要
npm test        # 全部测试（可选）
```
然后在 `chrome://extensions` 里加载仓库的 `extension/` 文件夹。

### 升级提示

从 1.1.0 升级：在 `chrome://extensions` 里点该扩展的**重新加载**，或删掉旧目录后用新 zip 重新加载一次。

## 三、使用

1. 打开[千星奇域创作者中心](https://act.mihoyo.com/miliastra_wonderland/developer?mhy_presentation_style=fullscreen&mhy_auth_required=true)并**登录**
2. 进入要分析的页面：
   - **奇域详情页**：数据中心 → 奇域数据 → 点开任意奇域
   - **奇匠数据页**：数据中心 → 奇匠数据
3. 点页面右下角蓝色「**导出奇域数据**」打开面板
4. 面板上依次选：**导出模式**（单表 / 分表）→ **导出区间**（近7日 / 近30日 / 全部）→ 单表模式下再选**分布区间**
5. 点「**导出 Excel (.xlsx)**」

> 页面是在装扩展之前打开的话，点一下工具栏扩展图标会自动注入脚本，不用手动刷新。

### 导出区间

| 区间 | 效果 |
| --- | --- |
| 近7日 | 表格只保留最近 7 天 |
| **近30日**（默认） | 30 天每日数据 |
| 全部 | 接口返回的全部天数 |

## 四、数据口径

- **来源**：`get_stage_detail` / `get_user_info`（官方接口，每天 6:00 更新昨日数据）
- **比率**：万分之一存储 → 除以 100（`6250 → 62.5%`）；`METRIC_VALUE_TYPE_SCORE` 按 100 归一（`10000 → 100`）
- **时长**：接口给秒数，表内同时给出可读形式
- **时间**：统一转为 `Asia/Shanghai` 可读时间
- **无效数据**：接口标记 `cur_invalid` 的天一律留空（不填 0），并写入「数据说明」表

## 五、常见问题

**Q：单表模式和分表模式该用哪个？**
想看趋势、算环比、做透视表 → **单表**；想逐项查看、或需要接口明细类工作表 → **分表**。

**Q：单表里某列没出现？**
该列在整个所选区间内都没有有效值，会被自动省略（避免一堆空列）。

**Q：单表里的占比列想换一套区间？**
面板「分布区间」下拉切换，重新导出即可。

**Q：面板显示「脚本未注入」？**
点扩展图标会自动注入；仍失败就刷新页面（`F5`）。

**Q：提示未登录 / 数据缺很多？**
先登录创作者中心。未登录时接口返回 `retcode: -100`，扩展会提示并退回页面采集（只有页面已渲染的 7 天数据）。

**Q：评论是全部历史吗？**
不是，是接口返回的评论列表（默认最近若干条）。
