# Miliastra Atlas v1.1.0 — 米游社千星奇域数据导出扩展

把**米游社千星奇域（Miliastra Wonderland）创作者中心**的奇域数据与奇匠数据，一键导出成可直接分析的 Excel 表格。

- 数据来自**官方数据接口**（与页面显示一致），不是截图式抓取
- **分类分工作表**：趋势、分布、评论、指标汇总各自成表，表头全中文
- **只导有意义的数据**：导航文字、调试信息、接口原始字段一律不进表格
- 零依赖 XLSX 生成器，扩展不加载任何远程代码

---

## 一、安装（3 步，无需构建）

1. 下载本页下方的 **`miliastra-atlas-v1.1.0.zip`** 并解压到一个**固定目录**（例如 `D:\miliastra-atlas`，装了就别删，Chrome 会一直引用它）
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）→ 打开右上角 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择解压出来的目录（里面有 `manifest.json` 的那一层）

> 也可以在本仓库根目录用 `extension/` 文件夹直接加载（源码方式）。

## 二、登录并导出

1. 打开 [千星奇域创作者中心](https://act.mihoyo.com/miliastra_wonderland/developer?mhy_presentation_style=fullscreen&mhy_auth_required=true) 并**登录**（扩展需要你的创作者中心登录态来调接口）
2. 进入要分析的页面：
   - **奇域详情页**：数据中心 → 奇域数据 → 点开任意奇域
   - **奇匠数据页**：数据中心 → 奇匠数据
3. 页面**右下角**出现蓝色「导出奇域数据」按钮 → 点开面板
4. 先选**导出区间**，再点 **导出 Excel (.xlsx)**

> 如果这个标签页是在装扩展之前打开的：点一下浏览器工具栏的扩展图标，它会**自动注入脚本**，不用手动刷新。

### 面板按钮

| 按钮 | 作用 |
| --- | --- |
| 导出 Excel (.xlsx) | 主产物，多工作表 |
| 导出 CSV | 单文件多段（`# 表名` 分段 + BOM，Excel 直接打开不乱码） |
| 导出 JSON | 接口原始响应，仅用于排查问题 |
| 数据自检 | 显示解析到的奇域ID、图表来源、已拦截接口、页面「标签:值」清单 |
| 刷新数据 | 页面切换后重新采集 |

### 导出区间

| 区间 | 效果 |
| --- | --- |
| **近7日** | 每张趋势表只留最近 7 天；汇总表给「近7日变化」（官方口径） |
| **近30日**（默认） | 30 天每日数据；汇总表给「近30日变化」 |
| **全部** | 接口返回的全部天数 |

选择会被记住，下次打开面板仍是上次选的区间。

## 三、导出的表格长什么样

一个 `.xlsx`，约 18 张工作表，按「先结论、后明细」排列：

| 工作表 | 内容 |
| --- | --- |
| **数据概况** | 奇域名/ID/状态/发布时间 + 本次关键指标 + 导出时间 |
| **关卡基础数据** | 项目-内容两列的基础信息 |
| **页面指标一览** | 页面各分组指标合并成一张：分组 / 指标 / 页面显示值 / 数值 / 单位 / 较昨日变化 |
| **关卡指标汇总** | 一行一个指标：当日数值、单位、较昨日、区间变化、变化值来源 |
| **奇域热度 / 平均游玩时长 / 评论数 / 封面点击率** | 日期 + 数值（时长另有可读列「5分23秒」），可直接插折线图 |
| **单局游玩时长分布** | **三套区间全导出**，用「区间组」列区分：常规（≤1/1-3/3-5/5-7/>7分钟）、长（≤3/3-6/6-9/9-12/>12）、超长（≤6/6-13/13-19/19-26/>26），每列为**占比%** |
| **单局时长分布_人数** | 同上，绝对人数 |
| **评论内容** | 用户 / UID / 评论时间 / 推荐态度 / 评论内容 / 点赞数 / 回复数 / 楼层 |
| **奇匠指标汇总** | 奇域总热度、热度排名、平均推荐率、游玩指数、奇域总数 + 区间变化 |
| **奇域总热度 / 平均推荐率(奇匠) / 游玩指数 / 奇域总数 / 订阅人数趋势** | 每项指标按所选区间的每日数值 |
| **数据说明** | 口径、区间、比率换算、缺失数据说明 |

**不会出现在表格里**：顶部导航文字、接口技术字段（`cur`/`delta`/`value_type`/`cur_invalid`/`retcode`）、接口原始 dump、调试数据、无有效数据的指标；无有效数据的天**留空而非填 0**。

## 四、数据口径

- **比率**：接口以「万分之一」存储，导出时除以 100（`6250 → 62.5%`）；`METRIC_VALUE_TYPE_SCORE` 按 100 归一（`10000 → 100`）
- **时长**：接口给秒数，表中同时给出可读形式（`323 → 5分23秒`）
- **时间**：统一转为 `Asia/Shanghai` 可读时间
- **区间变化**：优先用接口给的变化量；接口标记无数据时按该区间「首个有效点 → 末个有效点」计算，并在「变化值来源」列标注
- **数据来源**：`get_stage_detail`、`get_user_info`、`get_stage_list`（每天 6:00 更新昨日数据）

## 五、常见问题

**Q：面板显示「脚本未注入」？**
点扩展图标会自动注入；若仍失败，刷新页面（`F5`）再试。

**Q：提示未登录 / 表格缺数据？**
扩展用你浏览器里的登录态调接口。请先在创作者中心登录；未登录时接口返回 `retcode: -100`，扩展会提示并退回页面采集（此时只有页面已渲染的 7 天数据）。

**Q：某个指标整段是 0 或缺少几天？**
接口本身返回如此（`cur_invalid` 标记为无有效数据）。这类天在表中留空，不会用 0 污染分析，具体见「数据说明」表。

**Q：需要每次导出前先点页面的「近7日/近30日」吗？**
不需要。接口直接返回 30 天全量，面板上的区间选择决定导出多少天。

**Q：评论是全量历史吗？**
不是，是接口返回的评论列表（默认最近若干条）。
